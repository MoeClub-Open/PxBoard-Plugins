# 已拆分套餐升级

早期迁移器会将 Xboard / V2Board 同一套餐的每个价格周期拆成独立套餐。此工具将这些同源记录合并为一个带多周期价格的套餐，并保留每条原记录。使用新版商业插件和支持多周期的前端之前，请先备份并停止面板服务，再执行本工具；不要在服务运行时修改数据库。

需要 Node.js 24 或更新版本。使用服务器上的本地数据库绝对路径：

```sh
node tools/migrate-plan-periods.ts --database /srv/pxboard/data/pxboard.db
node tools/migrate-plan-periods.ts --database /srv/pxboard/data/pxboard.db --apply
```

第一条只读取数据库，输出每组准备保留的套餐标识和每个周期的价格、期限及销售状态。请核对后运行第二条。写入前工具另存一份数据库备份，备份目录是数据库文件名后加 `.plan-period-backups`；所有合并和原始记录归档在同一个数据库事务内完成。工具不会修改订单、订单中的套餐快照、访问账户或账本。用户权益中的套餐组标识不变；新套餐沿用一个原套餐标识，每个周期保留原拆分记录的标识。旧套餐原始记录完整保存在 `commerce/plan_period_archive` 集合中，数据库备份也包含原始数据。

只处理明确带有 Xboard / V2Board 来源、同一来源记录和 `sourcePeriod` 的套餐。周期价格、期限、类型、重置规则、出售与续费开关分别保存在对应周期中；其他字段（包括权益、币种、来源、限制和附加字段）必须完全一致。套餐名称的周期后缀必须与来源周期对应。若出现不一致、重复周期、未知来源或归档冲突，工具会停止整批写入；请先核对差异，不能简单以某个周期覆盖其他配置。

工具可重复运行，已经合并的套餐不会再次转换。不要单独删除已存档的旧套餐记录来回滚；如果确需恢复，请先停止服务，并按运维流程使用完整数据库备份，确保不会覆盖备份之后产生的用户数据。

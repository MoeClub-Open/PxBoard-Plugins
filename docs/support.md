# 用户服务

`support` 插件提供工单、公告、使用文档和邮件通知。普通用户只能读取、回复和关闭自己的工单；管理员可以处理全部工单。未发布的公告和文档仅管理员可见。

## 工单对话

工单内容和回复支持 Markdown 及常用扩展语法。用户和管理员可以上传 PNG、JPEG、GIF、WebP 图片，单张不超过 2 MiB；也可粘贴图片，或插入 HTTP / HTTPS 图片及视频链接。直接链接到 MP4、WebM、OGV 的视频在页面提供播放控件，其他视频地址以链接打开。图片和视频由访问者的浏览器加载，外部链接的可用性由其服务商决定。

新工单以独立消息保存作者、时间与内容；旧工单的纯文本对话原样保留，新回复单独保存，不重新解释旧文本。工单仅发起人和管理员可查看；上传图片仅上传者、相应工单发起人和管理员可查看。上传后尚未发送的图片仅上传者和管理员可访问。

上传图片保存在 `PX_PLUGIN_STATE_DIR/attachments/`，记录与权限信息保存在面板数据库。备份或迁移时必须一并备份完整面板数据目录；仅备份数据库无法恢复图片。升级或停用插件不会删除附件。上传但未发送的图片会保留在数据目录中。

接口：登录用户 `POST /api/v1/extensions/support/attachments`，JSON 正文 `{"data":"图片 Base64"}`，返回附件 `id` 与受权限保护的 `url`；`GET` 该地址返回图片。用户工单通过 `POST /tickets` 的 `content` 和 `POST /tickets/{id}/reply` 的 `message` 提交 Markdown；系统检查站内图片引用的权限。图片内容不是公开文件，不能直接作为免登录图床使用。

## 配置邮件

在“邮件通知”填写 SMTP 服务器、端口、发件地址和面板公开地址。587 端口使用 STARTTLS，465 端口直接使用 TLS。服务器证书必须有效；有登录认证要求时填写用户名和密码。更新配置时密码留空会保留原值，查询配置不会返回密码。

面板公开地址用于生成找回密码链接，例如 `https://panel.example.com`。启用有效邮件配置后，登录页显示找回密码入口。找回密码邮件中的链接有效期为 30 分钟；在队列里已经过期的找回邮件不再发送。

## 投递与重试

订单开通、管理员回复工单和找回密码请求会创建持久邮件记录。订单以订单编号、工单回复以回复编号去重，其他通知以事件编号去重；重复收到通知不会覆盖已有记录，也不会把已发送邮件重新放入队列。关闭工单不会发送回复通知。邮件在后台逐封发送，SMTP 连接缓慢不会占住面板请求。

工单回复与待通知记录一并保存。通知暂时无法入队时，回复仍然保存成功，后台稍后补发；同一工单的多条回复分别保留通知记录。

投递失败会记录错误并按逐渐延长的间隔重试，最多自动尝试 5 次。管理员可以在投递记录中选择“重新投递”。关闭邮件通知时保留队列，重新启用后继续处理；已经失效的找回密码链接不会补发。

投递记录不向界面返回邮件正文，成功或过期后也会移除保存的正文。SMTP 在接收邮件时连接中断，发送端可能无法确认是否已经接收；重试仍可能产生重复邮件。每条通知使用固定的 Message-ID，便于邮件服务识别。

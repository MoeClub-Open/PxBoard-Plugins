# 访问账户与分享邀请

`access` 保存用户的连接凭据、流量额度、到期时间、节点分组、限速和设备限制；`sharing` 在此基础上提供邀请注册与给已有用户分配访问权限。

## 访问账户

每个用户对应一个访问账户。账户编号创建后保持不变，NodeRS 使用该编号关联流量统计。导入用户保留原编号、连接凭据、已用流量及现有权益。

账户只有在核心用户启用、访问状态正常、未到期且仍有可用流量时下发到节点。不限流量需要显式开启，额度为零不会自动成为无限流量。用户只能读取自己的账户，管理员可以管理全部账户。

流量报告根据节点、批次和用户去重；同一批次重投不会重复扣量。手动重置流量会开始新的用量周期，历史统计仍保留。周期重置支持固定天数与带时区的日历规则；到期前尚未触发的规则不会反复改写，实际重置使用核心事务批量保存。

开通权益以业务 `grantId` 去重，退款只允许撤销当前账户最新一笔尚未退回的权益。权益使用明确的先后序号区分，同一秒开通的多笔订单仍按实际开通顺序处理。流量包、重置包或单独延时包需要先有基础账户。

## 分享邀请

管理员可以设定邀请码、可领取次数、访问天数、流量额度、节点分组和到期时间。领取次数按已保存的领取记录计数，开通中的记录也占用名额，避免在请求中断或重试时重复发放。

新用户通过“接受邀请”创建账户。已有用户登录后，可在“领取分享”中输入邀请码。同一用户领取同一个邀请码不会重复延长访问时间或重复扣减次数。

邀请码通过检查后，系统先保存领取记录及当时的权益，再调用访问账户插件开通。开通暂时失败时保留记录，每分钟继续重试，用户也可在“领取分享”中重试。注册已成功时会返回“账户已创建”，不会把已经创建的用户误报为注册失败。

修改邀请码的天数、额度或分组不改变已经领取及开通中的权益。删除邀请也不会删除已经分配的访问账户。

## 内部接口

以下路径位于 `/api/v1/extensions/access` 下，由核心校验调用插件权限。普通用户不能直接调用。

| 方法与路径 | 调用方与用途 |
| --- | --- |
| `GET /internal/clients` | 节点、订阅和分享插件读取当前可用账户 |
| `GET /internal/clients?userId=...` | 只读取指定用户的当前可用账户，返回数组 |
| `GET /internal/accounts` | 节点插件读取稳定编号与用户映射，不包含连接凭据或权益历史 |
| `GET /internal/accounts/{user}` | 商业插件读取指定用户权益；不存在时返回 `null` |
| `POST /internal/grant` | 商业或分享插件按业务编号开通权益 |
| `POST /internal/revoke` | 商业插件按业务编号撤销最新权益 |

分享插件的成员领取接口是 `POST /api/v1/extensions/sharing/claim`，请求体为 `{"code":"邀请码"}`。邀请码注册接口 `POST /api/v1/extensions/sharing/redeem` 还需提供邮箱、密码和姓名；注册成功但权益开通中时返回 `202`，账户可以正常登录。

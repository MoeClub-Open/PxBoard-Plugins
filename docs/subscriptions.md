# 订阅链接

用户可在“我的订阅”创建多条独立链接，分别命名、复制、重置或删除。重置后旧地址立即失效，同时解除该链接的客户端绑定；删除只影响这一条链接。原有订阅链接保持有效。通用地址根据客户端选择格式，普通浏览器默认得到 Mihomo 配置；也可使用 `format=clash`、`format=sing-box` 或 `format=uri` 指定格式。

创建时可选择绑定首次使用的客户端。该链接首次由客户端成功更新后记录请求标识中的客户端名称和主版本，允许次版本变化；其他名称或主版本的请求会被拒绝。重置链接可重新绑定。开启绑定的链接遇到常见浏览器访问特征时返回普通 404 页面，因此不能通过页面上的“下载配置”按钮下载。

客户端标识可以伪造，同一客户端在多台设备上也可能使用相同标识，绑定不能证明设备身份或阻止他人冒用；部分客户端使用浏览器式标识时可能无法使用绑定链接。请像密码一样保护订阅地址，泄露后及时重置。当前没有要求客户端执行计算验证，因为常见订阅客户端不支持该交互，不能依此可靠区分浏览器。

订阅验证默认关闭，可复用独立人机验证插件；启用后需要为每条链接单独验证，详情见[人机验证](captcha.md)。未验证的链接不显示地址，服务端也拒绝拉取；验证通过后客户端不需要每次更新都验证。

接口：`GET /api/v1/extensions/subscriptions/links?mine=1` 列出自己的链接；`POST /links` 可提交 `name` 和 `bindUserAgent`，只返回记录 ID；`POST /links/{id}/rotate` 重置，`DELETE /links/{id}` 删除。访问其他用户的链接需要管理员权限。

# 站点品牌

`branding` 是独立可选插件，适用于自用、按需分享和商业站点；公开首页扩展需要与同批次核心一起升级。

安装并启用后，在后台“站点设置”修改站点名称、Logo 地址和网站图标地址。站点名称、登录和注册页面、用户前台、管理后台、公开首页以及浏览器标题统一使用配置的品牌信息。

图片地址支持 HTTPS 完整地址或本站绝对路径，例如 `https://static.example.com/logo.svg`、`/assets/site-icon.png`。插件只保存地址，不上传图片或执行自定义 HTML、CSS。资源需要能够被访问站点的浏览器直接读取。

名称留空时使用核心的工作空间名称；未配置 Logo 或网站图标时使用界面的默认展示。停用插件后恢复核心工作空间名称和默认图标，插件配置仍保留，再次启用后继续使用。

## 接口

接口统一通过 `POST /rpc/v1/branding/{method}` 调用，响应使用 `{"data":...}`。

| 过程 | 用途 |
| --- | --- |
| `public.get` | 公开读取 `name`、`logoUrl`、`faviconUrl` 三个展示字段 |
| `settings.list` | 管理员读取品牌设置的单记录数组 |
| `settings.update` | 管理员更新站点名称、Logo 和网站图标 |

设置记录使用固定编号 `settings`，不提供重复创建入口。普通用户、匿名用户以及未获授权的插件不能修改品牌配置。品牌数据保存在 `branding/settings` 集合，独立于商业、推广、节点和兑换码插件。

## 商业首页和搜索分享

商业模式下提供服务端可读的公开首页，与品牌信息共用 `settings` 配置。首页配置包含标题 `heading`、品牌介绍 `introduction`、线路介绍 `routes`（`title`、`region`、`description` 数组）、功能特性 `features`（`title`、`description` 数组）及页脚 `footer`；旧版纯文本 `highlights` 自动读取为功能特性条目。搜索和分享使用 `seoTitle/description/socialImageUrl`；图片只接受 HTTPS 或本站绝对路径。`indexingEnabled` 默认 true，但只有核心确认模式、初始化与公开地址都满足条件时才允许收录。

`GET /_site` 仅供核心调用，接收 SDK `SiteContext`。`content=false` 时仅返回元数据；完整请求返回品牌介绍、线路介绍、功能特性、页脚与登录入口。首页插件不调用商业插件，不获取或输出任何套餐、价格、周期、流量额度，也不读取用户、订单、凭据或管理入口。

首页和浏览器元信息由同一份配置生成。首页标题留空使用站点名称，公开首页默认突出注册入口，关闭注册时改为登录。品牌介绍、线路介绍与功能特性均默认为空，由管理员按实际服务填写，不预设地区、线路质量或宣传文案，也不自动公开接入节点地址及状态。

自用模式仍可独立使用品牌信息，不产生商业首页。初始化向导收集常用站点字段，线路介绍、功能特性及其他搜索分享配置可在后台“站点设置 -> 首页与搜索”编辑，清空列表后对应分区自动隐藏；主动清空的品牌介绍在后续修改品牌名称或图标时继续保留为空。完整 HTTP 输出、隐私策略与站点地图规则见核心仓库的 `docs/public-site.md`。

# 站点品牌

`branding` 是独立可选插件，适用于自用、按需分享和商业站点；公开首页扩展需要与同批次核心一起升级。

安装并启用后，在后台“站点设置”修改站点名称、Logo 地址和网站图标地址。站点名称、登录和注册页面、用户前台、管理后台、公开首页以及浏览器标题统一使用配置的品牌信息。

图片地址支持 HTTPS 完整地址或本站绝对路径，例如 `https://static.example.com/logo.svg`、`/assets/site-icon.png`。插件只保存地址，不上传图片或执行自定义 HTML、CSS。资源需要能够被访问站点的浏览器直接读取。

名称留空时使用核心的工作空间名称；未配置 Logo 或网站图标时使用界面的默认展示。停用插件后恢复核心工作空间名称和默认图标，插件配置仍保留，再次启用后继续使用。

## 接口

路径前缀为 `/api/v1/extensions/branding`。响应使用 `{"data":...}`。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /public` | 公开读取 `name`、`logoUrl`、`faviconUrl` 三个展示字段 |
| `GET /settings` | 管理员读取品牌设置的单记录数组 |
| `PATCH /settings` | 管理员更新站点名称、Logo 和网站图标 |

设置记录使用固定编号 `settings`，不提供重复创建入口。普通用户、匿名用户以及未获授权的插件不能修改品牌配置。品牌数据保存在 `branding/settings` 集合，独立于商业、推广、节点和兑换码插件。

## 商业首页和搜索分享

商业模式下提供服务端可读的公开首页，与品牌信息共用 `settings` 配置。首页标题 `heading`、介绍 `introduction`、要点 `highlights`（每行一条）、页脚 `footer` 均为纯文本。搜索和分享使用 `seoTitle/description/socialImageUrl`；图片仍只接受 HTTPS 或本站绝对路径。`indexingEnabled` 默认 true，但只有核心确认模式、初始化与公开地址都满足条件时才允许收录。

`GET /_site` 仅供核心调用，接收 SDK `SiteContext`。`content=false` 时仅返回元数据；完整请求只返回品牌介绍、服务要点、页脚与登录入口。首页插件不再调用商业插件，不获取或输出任何套餐、价格、周期、流量额度，也不读取用户、订单、凭据或管理入口。

首页和浏览器元信息由同一份配置生成，默认输出中没有额外的虚构宣传数据。自用模式仍可独立使用品牌信息，不产生商业首页。初始化向导会收集常用字段，其余首页配置可在“首页与搜索”继续编辑。完整 HTTP 输出、隐私策略与站点地图规则见核心仓库的 `docs/public-site.md`。

首页采用品牌文字与装饰性网络插画，登录／注册入口集中在首屏，说明内容按配置显示。插画不代表在线节点或实际网络状态。桌面与移动端共用响应式布局，颜色随现有深浅主题变化。

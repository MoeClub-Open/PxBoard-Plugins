# 记录与事件提交升级

当前 `0.0.1` 开发构建增加核心 `Commit` 接口。请先升级核心，再更新官方插件。升级前停止面板，将旧订单和工单中的待发送通知搬入核心事件队列：

```sh
node tools/migrate-event-outbox.ts --database /var/lib/pxboard/pxboard.db
node tools/migrate-event-outbox.ts --database /var/lib/pxboard/pxboard.db --apply
```

工具需要 Node.js 24 或更新版本。默认只检查并输出数量；`--apply` 在一个事务中登记事件、投递任务及去重标识，并删除原记录中的通知标记。不会修改用户、套餐、订单金额、工单消息或订阅令牌，可以重复执行。操作失败整体回滚。按站点原有备份策略保存数据库；工具不创建额外备份文件。

订单开通、退款、支付流水和工单回复使用原子记录与事件提交。注册仍在用户创建时保留最小待发布记录，随后用同一原子接口发布，重试只查询待发布记录。跨插件权益发放和余额入账继续通过稳定业务编号防止重复执行。

升级后，后台用户、订单、余额明细、订阅和工单列表按页读取；用户选择框按输入搜索。节点和套餐的专用界面由官方界面注册管理。新导入任务依照目标插件声明检查凭据、用户归属和数字编号，缺少对应规则时提示先更新目标插件。
